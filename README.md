# 个人任务记事本（微信小程序）

## 1 How to Run

1. 打开 **微信开发者工具**。
2. 点击 **导入项目**。
3. 选择项目目录。
4. AppID 可选择测试号或使用您自己的 AppID。
5. 点击 **编译** 按钮运行模拟器。

## 2 Services

本项目使用 **本地存储**（`wx.setStorageSync` / `wx.getStorageSync`）模拟后端数据，无需外部服务器或云开发。

包含的服务：
- **认证服务**：本地用户注册与登录，密码经哈希后存储（`utils/crypto.js`）。
- **任务服务**：任务的增删改查（Create, Read, Update, Delete），支持按状态与关键词筛选。
- **主题服务**：在默认模式与护眼模式（暖色调）之间切换。

## 3 测试账号

数据存于本地，可注册任意账号。为便于测试可使用：

- **用户名**：`admin`
- **密码**：`123456`

（首次使用时若该账号尚未存在，可先注册再登录，或直接使用上述账号登录。）

## 4 题目内容

基于微信小程序的个人任务记事本设计与实现。要求：注册登录、护眼模式、任务开始/截止日期、任务优先级、任务类型，并额外增加若干功能，**不使用云开发**。

**功能列表（与当前实现一致）：**

- **注册登录**
  - 用户注册与登录，本地存储。
  - 登录页支持密码可见/隐藏切换。
  - 密码以哈希形式存储，兼容旧明文数据并自动迁移。

- **护眼模式**
  - 在个人中心通过开关切换默认/护眼主题。

- **任务管理**
  - **日期**：任务开始时间、截止时间，支持到**时分秒**选择。
  - **优先级**：高、中、低（任务卡片上显示优先级标签）。
  - **类型**：工作、个人、学习、其他（任务卡片上显示类型标签）。
  - **状态筛选**：任务列表顶部提供「全部」「待办」「已完成」三个 Tab，按状态筛选。
  - **搜索**：按任务标题或描述关键词实时搜索。
  - **列表展示**：任务按截止时间升序排列；卡片上显示逾期/即将到期标记。
  - **操作**：点击进入详情编辑、勾选切换完成状态、长按弹出「删除任务」。

- **任务统计**
  - 个人中心展示：总任务数、已完成、待办、已逾期、即将到期数量。
  - 任务完成率（百分比 + 进度条），随数据实时更新。

- **任务导出**
  - 导出当前用户任务列表为文本格式，可复制到剪贴板，便于备份或分享。

- **清理已完成**
  - 一键清除当前用户下所有已完成任务。

- **任务提醒**
  - 进入任务列表时检查 24 小时内到期的任务，若有则弹窗提醒，可跳转查看。

- **UI/UX**
  - 卡片式布局，阴影区分区块；Flex/Grid 布局，统一间距（如 8px/16px/24px）。
  - 交互反馈：Toast 提示、Loading、操作成功/失败提示；按钮悬停与加载状态。

## 项目结构

```
├── pages/
│   ├── login/      # 登录注册页
│   ├── index/      # 任务列表页（筛选、搜索、按截止时间排序）
│   ├── detail/     # 任务详情/新建·编辑页
│   └── profile/    # 个人中心（护眼模式、导出、清理、统计）
├── assets/
│   └── tabbar/     # Tab 栏图标（tasks / tasks-active / profile / profile-active）
├── utils/
│   ├── storage.js  # 本地存储（用户、任务 CRUD，支持 status/search 筛选）
│   ├── util.js     # 日期格式化、逾期/即将到期判断等
│   ├── crypto.js   # 密码哈希与校验
│   ├── export.js   # 任务导出为文本
│   └── reminder.js # 到期任务提醒
├── app.js
├── app.json
└── app.wxss
```
